# Analytics-dashboard-landing-page
Implementación de analítica web para un cliente con sitio estático en Firebase Hosting.  Entender si la estrategia de contenido generaba tráfico real y si los  usuarios navegaban el sitio o se ilban desde la home. La solución conecta GA4 a sitio existente y expone los datos en un dashboard de Looker Studio accesible para el cliente.
